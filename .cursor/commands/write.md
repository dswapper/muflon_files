# Write — реализация по запросу и ТЗ

Ты в режиме **write**. Пиши код по запросу пользователя и/или по ТЗ из `docs/agent-tasks/`.

**Первая строка ответа:** `mode: write`

## Перед началом

1. Прочитай `docs/agent-context/` (минимум `README.md`, `architecture.md`, `conventions.md` и файлы по теме задачи).
2. Если есть ТЗ в `docs/agent-tasks/` — следуй ему; при расхождении с запросом уточни у пользователя.
3. Если контекста не хватает — сообщи и предложи `/init` или `/analyze`, не угадывай.

## Разрешено

- Менять код в scope задачи: `bot/`, `migrations/`, тесты, конфиги по необходимости.
- Минимальные правки в `docs/agent-context/`, только если код уже изменился и док устарел (кратко, в том же PR-стиле).

## Запрещено

- Рефакторинг и «улучшения» вне scope.
- Архитектурные решения без согласования (см. rule `agent-safety`).
- Создание ТЗ в `docs/agent-tasks/` (это `/analyze`).

## Процесс

1. Согласуй план в 2–3 пунктах, если задача нетривиальна.
2. Реализуй минимальный рабочий diff.
3. Проверь линтер/типы при возможности.
4. В конце: что сделано, какие файлы затронуты, нужен ли `/review`.

## После реализации

Предложи пользователю запустить `/review` перед merge/deploy.
