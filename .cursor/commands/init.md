# Init — инвентаризация проекта и база знаний

Ты в режиме **init**. Осмотри репозиторий и создай/обнови документацию в `docs/agent-context/`. **Исходный код не меняй.**

**Первая строка ответа:** `mode: init`

## Разрешено

- Читать любые файлы проекта.
- Создавать и обновлять только файлы в `docs/agent-context/`.
- Запускать read-only команды (`tree`, `git log`, `poetry show` и т.п.).

## Запрещено

- Любые правки кода, миграций, Docker, CI, `.env`.
- Создание файлов в `docs/agent-tasks/` (это зона `/analyze`).

## Обязательные файлы

Создай или полностью обнови **все** перечисленные файлы:

| Файл | Содержание |
|------|------------|
| `docs/agent-context/README.md` | Оглавление, дата последнего обновления, краткое описание проекта, ссылки на остальные файлы |
| `docs/agent-context/architecture.md` | Слои (handlers → services → models → db), DI (`container.py`), middleware, потоки данных, ключевые модули |
| `docs/agent-context/security.md` | Секреты (`.env`), токен бота, Postgres/Redis, угрозы, что нельзя логировать, рекомендации |
| `docs/agent-context/contracts.md` | Публичные контракты: хендлеры бота, команды, фильтры, сервисы, внешние API (Telegram, GHCR) |
| `docs/agent-context/data-model.md` | SQLAlchemy-модели, связи, миграции Alembic, инварианты данных |
| `docs/agent-context/operations.md` | Docker Compose, переменные окружения, CI/CD (`.github/workflows`), деплой, локальный запуск |
| `docs/agent-context/conventions.md` | Стиль кода, структура каталогов, паттерны (сервисы, middleware, исключения), как добавлять фичи |

## Процесс

1. Пройди `bot/`, `migrations/`, `docker-compose*.yml`, `.github/`, `pyproject.toml`, `.env.example`.
2. Заполни каждый файл фактами из кода; не выдумывай — помечай неясное как `TODO: уточнить`.
3. В `README.md` укажи версию/коммит или дату инициализации.
4. В конце отчитайся: какие файлы созданы/обновлены, что осталось неясным.

## Для последующих режимов

Документация в `docs/agent-context/` — единственный источник правды для `/analyze`, `/write` и `/review`. Поддерживай её актуальной при значительных изменениях в коде.
